# Juan Messi Tulengkey - Personal Web Portfolio

A clean, modern, and elegant personal portfolio web application built with React and Vite. This project showcases my profile, technical skills, and projects as an Informatics student at Universitas Klabat.

## 🚀 Tech Stack

- **Core:** React + Vite
- **Styling:** CSS
- **Development:** Vite
- **Code Quality:** ESLint

## ✨ Features

- **Responsive Design:** Layout optimized for desktop and mobile devices.
- **Modern UI/UX:** Clean typography, minimalist interface, and smooth transitions.
- **Personal Portfolio:** Showcases profile, skills, and projects.
- **Networking & IT:** Highlights knowledge and projects related to computer networking and information technology.
- **AI & RAG:** Includes experience and projects related to Artificial Intelligence and Retrieval-Augmented Generation.
- **Web Development:** Built using modern React development tools.
