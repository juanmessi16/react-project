# Juan Messi T. - Personal Web Portfolio

A clean, modern, and elegant personal portfolio web application built with React and Tailwind CSS. Designed with a touch of the FC Barcelona "Blaugrana" aesthetic, this project showcases my profile, technical skills (Networking, AI/RAG, and Web Development), and projects as an Informatics student at Universitas Klabat.

## 🚀 Tech Stack

* **Core:** React (powered by Vite)
* **Styling:** Tailwind CSS
* **Deployment:** (You can add Vercel/Netlify here later)

## ✨ Features

* **Responsive Design:** Fully fluid layout optimized for both mobile and desktop screens.
* **Modern UI/UX:** Clean typography, minimalist interface, and smooth hover transitions.
* **Custom Theme:** Integrated custom color palettes inspired by FC Barcelona.
* **No Extra Libraries:** Built purely with React built-in features and Tailwind utility classes.
